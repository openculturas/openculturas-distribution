# Favicons for your theme

The default OpenCulturas favicons and site.manifest have been copied to your theme. Now you want to replace them.

## Required steps

1. Provide icon graphics, optimally SVG 512 x 512 pixels but suitable for very small sizes.
2. Build the variants accordingly (see copied files). A tool like [RealFaviconGenerator](https://realfavicongenerator.net/)
could be a convenient helper.
3. Replace the icons but keep the file names.
4. Replace "OpenCulturas Sub" in site.webmanifest with your site name.
5. Clear caches.

Reload the page and check whether you see your icon in a browser tab.
